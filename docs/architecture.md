현재 앱 소스와 `package.json`은 없습니다. 앞선 대화에서 제안한 소스 폴더 구조는
아직 확정된 설계가 아니며, 프로젝트 초기화 방식과 기능 경계에 맞춰 정합니다.

개발 PC에서 확인한 도구 버전과 프로젝트의 버전 지정 상태는
[프로젝트 환경 및 버전 명세](environment.md)에서 관리합니다.

### DEC-002: 루트의 docs 폴더에서 문서 관리

- 날짜: 2026-10-27
- 상태: 적용
- 근거: 요구사항과 스펙을 대화 밖의 프로젝트 산출물로 관리하려는 사용자 요청입니다.
- 결정: 요구사항, 기술 설계, 개발 계획을 Markdown 파일로 작성하고 코드와 함께 Git으로 관리합니다.
- 이유: 앱 패키지나 외부 문서 도구를 설치하지 않고도 변경 이력을 확인할 수 있습니다.
- 영향: 기능이나 기술 결정이 바뀌면 관련 문서도 갱신합니다.
