# 요구사항

최종 갱신: 2026-10-27

## 제품 개요

- 프로젝트명: `fishing`
- 제품: 출조노트 모바일 앱
- 개발 방식: React Native + Expo
- 목표 플랫폼: Android, iOS
- 배포 목표: 양쪽 앱 스토어 정식 출시

위 내용은 연결된 ‘시작’ 대화에서 확인한 사용자 요청을 기준으로 합니다.
구체적인 사용자 흐름과 기능 범위는 아직 합의하지 않았습니다.
