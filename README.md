# fishing

출조노트를 React Native + Expo 기반 모바일 앱으로 개발하는 프로젝트입니다.
Android와 iOS 스토어 출시를 목표로 합니다.

현재 단계는 요구사항 정의이며, 앱 초기화와 패키지 설치는 아직 진행하지 않았습니다.

## 프로젝트 문서

문서는 [`docs/README.md`](docs/README.md)에서 시작합니다.

- [요구사항](docs/requirements.md): 만들 제품, 확정된 요구사항, 미결정 사항
- [프로젝트 환경 및 버전](docs/environment.md): 개발 PC 환경, 도구 버전, 앱 패키지 버전 지정 상태
- [기술 설계 및 결정 기록](docs/architecture.md): 기술 구성과 결정 이유
- [개발 계획](docs/plan.md): 진행 순서, 작업 상태, 완료 기준
- [채팅 내용](docs/채팅%20내용.md): 지금까지의 대화, 결정 사항과 맥북에서 이어가는 방법

문서와 코드는 같은 저장소에서 Git으로 관리합니다.
